# CalculadorDeNotas
Este proyecto de consola permite calcular las notas de cualquier alumno.
# Descripcion
ESte proyecto consola toma las notas finales de cada corte de un alumno y lo divide entre tres, 
dando como resultado  la nota final de un estudiantes.
# Requisitos 
 Lenguaje Python
 Python 3.x 
 # Uso
# Clonar el repositorio
git clone https://github.com/hecarde2/CalculadorDeNotas.git

# Entrar a la carpeta del proyecto
cd CalculadorDeNotas

# Ejecutar la calculadora de notas
python3 CalculadoraNotas.py
